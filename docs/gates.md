# Gates por dependência real

| Gate | Evidência necessária | Bloqueia |
| --- | --- | --- |
| G-PUBLIC | allowlist, revisão humana e novo histórico autorizado | publicação |
| G-PROTECTION | PR/checks e proteção efetiva confirmados pela API | fechamento 01/merge |
| G-WORKERS | isolamento, capacidade e fluxo próprio comprovados | testes pesados desde 02 |
| G-OIDC | clientes/audiências e política de sessão aprovados | configuração real 03 |
| G-SOURCES | direitos, produtor e provas de publicação/contato | dados reais 04/10 |
| G-AI | limite financeiro externo, modelo e tráfego aprovados | qualquer chamada paga |
| G-PRIVACY | consentimento, retenção, minimização e descarte verificados | dados pessoais reais |
| G-TTS | fronteira dedicada, identidade/custo/privacidade autorizados | síntese real |
| G-SIGN | custódia e assinatura externa ao CI autorizadas | APK assinado |
| G-DEPLOY | recursos, storage, backup externo, restore, HTTPS e rollback | implantação 10 |

Especificação e testes offline não dependem de credenciais ou chamadas reais.
Configurações de contas e inventários de operação não pertencem à documentação pública.
